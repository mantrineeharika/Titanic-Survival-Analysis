Titanic Survival Data Analysis

📌 Project Overview

This project explores the Titanic dataset to understand the key factors that influenced passenger survival. Using Python libraries like pandas, matplotlib, and seaborn, the project covers complete data cleaning, exploratory data analysis (EDA), and visualization.

The goal is to identify patterns in survival rates based on gender, age, passenger class, fare, and other variables.

🎯 Key Features

Comprehensive data cleaning and preprocessing

Detailed EDA with step-by-step explanations

Multiple visualizations to show patterns clearly

Analysis based on passenger demographics and socio-economic factors

Clean and professional project folder structure

Easy to extend or reuse for other datasets

🛠️ Technologies & Libraries

Python 3

⭐ Key Insights

Female passengers had a significantly higher survival rate.

First-class passengers survived at much higher rates.

Younger passengers had better chances of survival.

Higher fare and higher class showed strong correlation with survival.

Families traveling together had different survival patterns than solo travelers.
